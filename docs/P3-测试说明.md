# P3 测试说明（0.4.0：变换工具）

安装方法与 P0/P1 相同：Blender 偏好设置 → 插件 → 从磁盘安装，选择
`build/sketchup_modeling-0.4.0.zip`（旧版本先禁用再装新版，或直接覆盖安装）。
适配 Blender 4.2+–5.x；界面语言跟随 Blender（中/英）。

本版本新增：Move（M）、Rotate（Q）、Scale（S）、Push/Pull（P）、Offset（F）、
Follow Me、Flip。连同 P1/P2 的选择、画线、橡皮擦、9 个形状工具一起，
共 19 个可用工具。

## 各工具用法

- **Move（M）**：先选好内容（或直接点一个实体），单击定参考点，移动鼠标，
  再单击完成；也可按住拖拽、松开即完成。Ctrl = 复制；复制后输 `3x` 作
  外部阵列、输 `3/` 作内部阵列（共 N 个副本）。只选中部分几何时移动，
  未选中相连部分随之拉伸。Measurements：距离（如 `500`）、全局坐标
  `[3000,500,0]`、相对坐标 `<500,0,0>`；做完后重输可改。
- **Rotate（Q）**：先选好内容。单击定中心，单击定参考方向，移动鼠标旋转，
  单击完成。中心处按住拖到另一点松开 = 沿折线定旋转轴（折叠模式）。
  Ctrl = 旋转副本，可接 `3x`/`3/` 环形阵列。Measurements：角度（如 `45`、
  `8:12` 坡度）；做完后重输可改。
- **Scale（S）**：先选好内容，出现包围盒手柄。角手柄 = 等比缩放，面/边手柄
  = 单向缩放；Ctrl = 绕中心缩放，Shift = 强制等比。Measurements：比例
  （如 `1.5`）或带单位的绝对尺寸（如 `10m`）；做完后重输可改。
- **Push/Pull（P）**：单击一个面，移动鼠标拉伸，单击完成；输距离可精确控制，
  做完后重输可改。Ctrl = 保留起始面（生成独立的拉伸体）。双击另一个面 =
  用上一次的距离再拉一次。
- **Offset（F）**：单击一个面（或先选中 ≥2 条共面相连的边），移动鼠标定偏移
  距离，单击完成；输距离可精确控制，做完后重输可改。双击另一个面 =
  用上一次的距离再偏移一次。
- **Follow Me**：先用选择工具选中连续的路径边，再激活 Follow Me，单击截面，
  截面沿整条路径放样。本阶段只做自动模式；路径须连成一条链。
- **Flip**：先选好内容，方向键选翻转平面（右=红轴、左=绿轴、上=蓝轴），
  单击翻转；Ctrl+单击 = 生成镜像副本。

## 已知限制（本阶段）

- Push/Pull 推入只对独立的面正确；在实体的面上推入做凹坑、推穿打洞，
  需要 P4 的带洞面模型，暂不支持。
- Follow Me 只有自动模式；手动拖拽模式在 P4。角部用斜接平面算法，
  极锐角处可能截断（属自定算法，官方未规定）。
- Scale 的边手柄取主导轴缩放，是近似实现；官方对边手柄的轴向语义
  未逐字确认。
- 阵列每次复制各推一个 Undo 步（SketchUp 里阵列是一步），后续收敛。
- 面内独立闭合环仍会生成重叠内面（P1 已知限制，留 P4）。
- 工具栏图标仍为 Blender 内置占位图；ScreenTip 中文措辞未经真机截图核对。
- Circle 默认 24 段未核实（官方正文无数字），Arc 默认 12 段有官方依据。
