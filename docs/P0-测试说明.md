# P0 测试说明（骨架版 0.1.1）

## 0.1.1 修复（2026-11-17）

Sen 真机反馈 0.1.0 中英混杂：子菜单标题是中文、里面的工具项是英文。原因查到了：Blender 对 `layout.operator(text=...)` 的文字是原样显示、不翻译，只有 `layout.menu(text=...)` 的标题才走翻译——所以只靠注册翻译字典，菜单里的工具项永远显示英文。

0.1.1 改为显式查表：全部绘制代码先用 `translate()` 按当前语言查好文字再显示，中文界面下每个菜单项、面板文字都显示核定的 SketchUp 中文标签，英文界面下全部显示英文。T2 新增假布局绘制捕获检查，在中/英双语下逐项核对全部 9 个菜单与 2 个面板的显示文字，四版本全部通过。

## 这个包是什么

P0 是地基，只有骨架、没有建模工具。装上之后能看到 SketchUp 的菜单、面板和工具栏骨架，点里面的工具只会提示“尚未实现”，不会建模。这是正常的，建模工具从 P1 开始一个一个做。

包含内容：

- Extension 骨架（manifest、注册/注销）
- 菜单数据表：按你真机截图核定的 Tools / Draw / Camera 菜单结构，头栏“SketchUp”菜单、N 面板、工具栏三处都由同一张表生成
- 三档快捷键开关骨架（偏好设置里可见，P0 还没注册任何快捷键）
- 4.x–5.x 版本适配层（core/compat.py）
- 翻译字典骨架（中/英跟随 Blender 语言设置）
- VCB 数字解析与单位换算纯逻辑（分数、英尺-英寸、单位后缀、负数、分隔符都支持）

## 安装方法（你的 Blender 5.1.2，Windows）

1. 打开 Blender，Edit > Preferences > Get Extensions。
2. 点右上角的 Install from Disk（从磁盘安装），选中 `sketchup_modeling-0.1.1.zip`。
3. 安装后在列表里找到 SketchUp Modeling，勾选启用。

## 真机检查清单（请逐项确认）

1. 启用后，3D 视图顶上头栏出现“SketchUp”菜单，里面按顺序有 Camera、Draw、Tools 三个子菜单，点开内容和你 SketchUp 里的一致（顺序、分组、子菜单）。
2. 按 N 打开右侧栏，出现 SketchUp 分类，里面有 SketchUp Tools 和 Measurements (VCB) 两个面板。
3. 左侧工具栏出现 SketchUp 工具分组（6 个占位工具）。
4. 随便点一个菜单项，状态栏提示“尚未实现”，不报错、不崩。
5. 禁用扩展后，头栏菜单、N 面板、工具栏分组全部干净消失；再启用又都回来。
6. 语言切换：Blender 语言设中文时，菜单/面板显示中文；设英文时显示英文（见下面“已知限制”里的 21 条例外）。
7. 偏好设置里能看到 SketchUp Modeling 的设置页：快捷键档位（默认 SketchUp 模式）、默认单位（默认毫米）、启用推断。

## 已知限制（请知晓）

1. 所有工具都是占位，点选只提示、没有任何建模功能——P0 本来就没有工具。
2. 0.1.1 起菜单/面板文字走显式查表，不再受 Blender 内置译文冲突影响：中文界面下显示的都是核定的 SketchUp 标签（如镜像、转动、顶视图）。21 条与 Blender 内置字符串重名的词条（清单见 0.1.0 版说明）仅影响个别类级标签的中文措辞（如偏好设置里的 Off 可能显示“关”而非“关闭”），显示的仍是中文，不造成中英混杂。
3. 工具栏图标是 Blender 内置占位图标，不是 SketchUp 的图标；自定义图标后续阶段换。
4. 右键菜单不在 P0 范围，后续阶段做。
5. 头栏菜单和工具栏的实际显示效果只能真机看，这边 headless 只能验证注册不报错——所以上面清单第 1、3 项请你重点确认。
