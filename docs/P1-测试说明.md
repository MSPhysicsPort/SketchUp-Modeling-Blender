# P1 测试说明（地基版 0.2.0）

## 这版有什么

P1 是第一个能真正建模的版本：选择、直线、橡皮擦三个工具可用，带推断引擎、自动成面/愈合、Measurements（VCB）输入。菜单里这三个工具已接真实操作，其余仍是占位。

- **直线（L）**：单击定点、连续画折线；闭合即成面；面上画线分割面；Esc 重开当前线段、右键结束。
- **推断**：端点、中点、交点、面上、边上、原点、参考点推断 + 红/绿/蓝轴向对齐 + From Point；方向键锁定轴向、Shift 锁定当前方向、Alt 循环线性推断开关（仅直线工具）。
- **VCB**：画线时直接输数字 + 回车定长度；画完一段、鼠标没动时再输数字 + 回车可改上一段长度；`[x,y,z]` / `<x,y,z>` 坐标输入。数值同时显示在视窗右下角 VCB 框、N 面板、工具头栏三处。
- **选择（Space）**：单击选、拖拽框选（向右拖只选完全在框内的、向左拖选相交的）、Shift 切换、Ctrl 加入、Ctrl+Shift 减去；双击面选面+边界边、双击边选边+相连面、三击选全部相连实体。
- **橡皮擦（E）**：单击删边及相连面（删分隔线后面愈合）、拖拽连续擦；Ctrl 软化+平滑、Shift 隐藏、Alt 取消软化。
- **快捷键**：档位 1 默认注册 Space / L / E；偏好设置里可切档位 0（不注册）/ 2（Alt+键）。

## 安装

1. Blender → Edit → Preferences → Get Extensions（4.2+）或 Add-ons。
2. 先禁用旧版（0.1.x）再从磁盘安装 `sketchup_modeling-0.2.0.zip`（覆盖安装亦可），启用。
3. 空场景直接用：工具会自动建一个 "SketchUp Model" 网格对象并进入编辑模式。

## 真机检查清单（只能你那边验）

1. **画线成面**：L 画矩形，第四条边落下时出面；画对角线变两个面；E 点对角线，面愈合回一个；面上画线分割面；Ctrl+Z 一次撤销一段。
2. **推断标记**：悬停端点/中点出标记 + 提示文字；画线时沿轴方向出红/绿/蓝线；方向键锁定轴向（再按同键解除）；Shift 按住锁定方向、松开解除；Alt 循环三种线性推断状态。
3. **From Point**：光标在某点停留一下再移开，应出现从该点出发的轴向虚线。
4. **VCB**：画线时输 `1000` 回车，线长 1000mm；刚画完一段、鼠标不动时输 `500` 回车，上一段改成 500mm；输 `[1000,500,0]` 回车定点。右下角 VCB 框、N 面板、工具头栏三处数值一致。
5. **选择**：单击、框选两个方向、双击/三击、Shift/Ctrl/Ctrl+Shift 四种修饰。
6. **橡皮擦**：单击删边、拖拽连擦、Ctrl 软化、Shift 隐藏、Alt 取消软化。
7. **导航**：画线中按中键旋转、滚轮缩放，工具不退出。
8. **快捷键**：Space / L / E 激活工具；偏好设置里切档位 0 后按键不再激活、切档位 2 后 Alt+键激活。
9. **工具栏**：Object 模式和 Edit 模式下工具栏都有选择/直线/橡皮擦，点工具后再点视窗开始用。
10. **语言**：推断提示文字、VCB 标签、工具提示的中英文是否统一（提示文字的中文措辞尚未对照 SketchUp 真机截图核对，如与 SketchUp 实际中文不一致请告诉我原文）。
11. **中文显示**：视窗里的提示文字和 VCB 框中文是否正常显示（不是方框）。
12. **禁用干净**：禁用插件后菜单/面板/工具栏/快捷键全部消失，无报错；再启用一切恢复。

## 已知限制（这版不修，留待后阶段）

- 在已有面内部画闭合环，会生成重叠的内环面（带洞面的逻辑面模型在 P4）。
- 圆心推断只对以后插件工具画的圆/弧有效，导入网格没有圆心元数据。
- 平行/垂直/延长线/相切推断、复合推断（双约束）还没做；↓ 键目前是方向锁定开关（近似实现）。
- 参考线数据、推断候选和绘制已就绪，但还没有创建参考线的工具（Tape Measure 在 P6）。
- 大模型下每帧全量投影候选，没有空间索引，鼠标移动可能卡顿（后续优化）。
- 首次启用时接管单字母键的提示弹窗还没做（P2 补）。
- 工具栏图标是 Blender 内置占位图，自定义图标后续补。
- 悬停鼓励停留阈值 0.35 秒、轴向吸附角 8 度是调参初值，体感不对请告诉我。
