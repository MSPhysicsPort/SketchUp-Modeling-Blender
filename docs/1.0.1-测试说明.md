# 1.0.1 测试说明：真机反馈四项修复

版本：1.0.1（Blender 4.2+，主测 5.1.2）。修复 Sen 2026-11-17 真机简单测试报的四个问题。安装方法同 1.0.0：从磁盘安装 zip 覆盖旧版，开 SU 模式开关。

## 修复内容

**1. 推/拉不再产生多余的线和面。** 之前拉实体表面时，原来的面会留在体内、接缝处多一圈线（立方体顶面拉高后是 11 个面、4 条三面共边）。现在拉动时相邻面跟着拉伸、原来那个面不再残留，立方体顶面拉高后是干净的 6 个面、12 条边；单独一个面拉起仍是带底面的盒子；VCB 改数值重拉、Ctrl 保留起始面、向内推、推穿打洞行为不变。

**2. 在面上画封闭图形可以扣洞了。** 之前在面内画圈/画框只会叠一个重合的面，删不掉、推不动。现在面内封闭图形会把原来的面切成环形三角面 + 里面的独立面：删掉里面的面就留下一个真洞；推/拉里面的面可以做凹坑或打穿。环是三角剖分，编辑模式下能看到剖分线，实体视图下共面看不出；环内再套一层同样处理。贴着面边界或压着边界画的图形仍是老行为。

**3. 圆（C）封面了。** 之前默认 24 段的圆只出线不出面（成面搜索的环长上限是 16，24 段的圈搜不到）。现在上限提到 32，且形状工具提交后会按已知闭合环直接补面，48 段的圆也能封面。

**4. 成组（G）不再报错。** 之前选中含零长边（两个端点重合）的几何按 G 会报 `edges.get(...): found the same (BMVert) used multiple times`。原因是边标志回写时按坐标重找端点，重合坐标坍缩成同一个顶点。现在回写优先按边序号重取、坐标校验，退化边直接跳过；成组复制时也不再复制零长边。

## 真机复核清单（Sen 随手测）

1. 立方体顶面推拉拉高：侧面是一整面、无横向接缝线；删顶面后里面是空的、无残留面。
2. 地面画矩形 → 在矩形里画圆 → 删圆面：留下一个圆洞；再画一个圆 → 推圆面到底：打穿成洞。
3. 按 C 画圆：直接有面；改边数 48 再画：也有面。
4. 全选立方体按 G：正常成组、不报错。

## 自测数据

- T0 打包验证 + T1：94 项；T2：119 项，四版本（4.5.16 / 5.1.2 / 5.2.4 / 5.3.0）全绿。新增回归测试：24/48 段圆成面、环切分与扣洞、嵌套环、退化边标志回写、推拉拉伸（实体/孤面/混合/反向/零距离/保留起始面/重输数值）、成组退化边。
- 偏移（F）工具的自测期望随环切分更新：面内偏移后为 8 三角环面 + 1 里面面（原来是 2 个重合面），属同一修复的正确结果。

## 已知限制（未变）

- 1.0.0 测试说明里的限制仍然有效（旋转无交互拾取中心、缩放无包围盒手柄、两点透视近似、反面材质、容器材质烤入、剖切性能、Walk 基础版、按标记着色为包围框）。
- 环切分只处理严格位于面内的闭合环；贴边、压边、跨边的图形仍可能重叠，须先用画线/橡皮擦整理。
- 直线工具手画超过 32 段的闭合圈仍不自动成面（形状工具不受限）。
