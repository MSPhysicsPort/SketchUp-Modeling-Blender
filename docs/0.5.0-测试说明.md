# 0.5.0 测试说明：SU 模式开关 + 原生变换

版本：0.5.0（Blender 4.2+，主测 5.1.2）。上一版 0.4.0 的快捷键问题已找到根因并修复，本版按 Sen 的框架要求重做：一个激活开关 + 同类工具优先用 Blender 原生。

## 先看结论：0.4.0 快捷键为什么没反应

已用真实按键复现并定位（不是注册漏了）：0.4.0 把快捷键只注册在 "3D View" keymap 里，但 Blender 事件分发先查模式 keymap（Mesh / Object Mode），再查 "3D View"。编辑模式下 Mesh keymap 吃掉了 R/S/A/L/E/M/F/P，对象模式下 Object Mode 吃掉了 A/R/S/M，事件到不了我们的条目。更关键的是实测证明：addon 的 "Mesh" / "Object Mode" keymap 根本不被事件系统查阅（重启对照 + 隔离键实验）。

0.5.0 的修复：开 SU 模式时，除了注册三个 keymap，还临时禁用 active keyconfig 里与我们键位冲突的默认条目（Mesh / Object Mode / Frames 三个 keymap，只动冲突项），事件落到我们的条目上；关模式时逐项恢复原状。被禁用的清单记在插件偏好里，即使保存了设置后重启也能精确恢复，不会动用户自己禁用的条目。

## 安装

1. Blender → 编辑 → 偏好设置 → 插件（Get Extensions）→ 从磁盘安装，选择 `sketchup_modeling-0.5.0.zip`。
2. 启用后**默认什么都不变**：Blender 的快捷键、吸附、模式全部原样。必须先开开关（下一步）。

## 第一步：打开 SU 模式开关

以下任选其一，效果相同：

- 3D 视图头栏的 **SU Mode** 按钮（点一下按下=开启，再点=关闭）。
- N 面板 → SketchUp 分类 → 顶部的 **SketchUp Mode** 开关。
- 搜索菜单（F3）→ `Toggle SketchUp Mode`。

开启后：状态栏提示“SketchUp 模式已开启：11 个快捷键生效”；自动进入编辑模式（SketchUp Model 对象）；吸附自动打开（端点/边/中点/面/面中心）；变换轴心改为 3D 游标。关闭后：快捷键、吸附、轴心、对象模式全部恢复原样。

## 快捷键（仅 SU 模式开启时生效）

Space=选择、L=直线、E=橡皮擦、R=矩形、C=圆、A=两点圆弧、M=移动、P=推/拉、Q=旋转、S=缩放、F=偏移。其他工具（旋转长方形、多边形、圆弧、3 点圆弧、扇形、手绘线、路径跟随、翻转）走工具栏 / SketchUp 菜单 / N 面板。

偏好设置里的快捷键档位仍有效：档位 1 单字母，档位 2 Alt+字母；档位切换只在模式开启时生效。

## 移动 / 旋转 / 缩放：改用 Blender 原生工具

M/Q/S 现在直接调用 Blender 的移动/旋转/缩放工具（拖拽、X/Y/Z 轴约束、数字输入都是 Blender 原生手感），并叠加 SU 行为：

- **吸附**：拖拽时自动吸附端点、边、中点、面、面中心。
- **复制**：按住 Ctrl 再按 M/Q，复制一份后再移动/旋转（相当于 Shift+D）。
- **轴心**：旋转/缩放围绕选择中心（3D 游标自动放到选择中心）。
- **阵列**：复制移动/复制旋转后，F3 搜 `Repeat Array`，输数量：`3x` 式外部阵列（手动那份算第 1 份，共 N 份）或勾 Internal 做 `/3` 式内部阵列。旋转阵列需在对话框里输入旋转角度（交互旋转不回报告角度，无法自动得知）。

其余工具（直线、形状、推/拉、偏移、路径跟随、翻转、选择、橡皮擦）没有原生等价物，仍用原来的 SU 式实现，VCB 输入方式不变。

## 本轮还修了两个真机 bug

- 偏移工具在有预选边时启动崩溃（丢了一个内部方法定义），已修复并补了回归测试。
- 形状工具按 Esc 取消当前段时可能崩溃（返回了布尔值而非 modal 结果集），7 个工具已统一修复，基类也加了兜底。

## 自测数据

- T0/T1：94 项全过；T2：108 项，四版本（4.5.16 / 5.1.2 / 5.2.4 / 5.3.0）全绿。
- 交互流程：选择/直线/橡皮擦、9 个形状工具、原生移动/旋转/缩放 EXEC 路径 + 阵列、推/拉/偏移/路径跟随/翻转，全部通过。
- 真实按键 harness（Xvfb + X 事件）：开模式后 11 个键逐一实测，8 个 modal 工具全部激活，M/Q/S 正常委托原生工具且无报错，G 等未绑定键仍走 Blender；关模式后默认快捷键/吸附/轴心全部恢复。

## 已知限制（本版有意为之，待后续）

- 旋转不再有交互拾取中心/折叠轴：轴心固定为选择中心；后续可加拾取前置步骤。
- 缩放不再有包围盒手柄：用原生轴约束键与数字输入。
- 旋转阵列需手动输角度（见上）。
- 移动/旋转/缩放的 VCB 重输随原生委托取消，改用原生数字输入。
- 推/拉打穿成洞、实体面凹坑、路径跟随手动模式，仍在 P4。
- 工具栏图标为 Blender 内置占位图。
