# 1.0.0 测试说明：全量版（P4+P5+P6）

版本：1.0.0（Blender 4.2+，主测 5.1.2）。本版按 Sen 2026-11-17 的三点反馈一次做完：① 群组/组件概念已加入；② 工具之间可直接按快捷键切换，不用先按 Esc；③ P4+P5+P6 全部工具做完再发。沙盒工具按已批方案（D10）不进首期。

## 安装

1. Blender → 编辑 → 偏好设置 → 插件（Get Extensions）→ 从磁盘安装，选择 `sketchup_modeling-1.0.0.zip`（会覆盖旧版）。
2. 启用后**默认什么都不变**：必须先开 SU 模式开关（3D 视图头栏 **SU Mode** 按钮，或 N 面板 → SketchUp → SketchUp Mode 开关，或 F3 搜 `Toggle SketchUp Mode`）。

## Sen 反馈的三点，本版的落实

**1. 群组 / 组件。** 选中几何按 G 成组（或 SketchUp 菜单 → 编辑 → 建立组件）。成组后几何不再与周围粘连；双击进入群组/组件内部编辑，点空白处逐层退出，Esc 或菜单“关闭群组/组件”回到顶层。组件多实例共享同一定义，改一处处处改；“设为唯一”可脱离定义。N 面板的“大纲视图”显示嵌套树，“实体信息”显示类型/定义/实例数/锁定。出于 Blender 结构限制：群组/组件是独立 Mesh 对象（不是 SketchUp 内部的实体类型），但双击进出、嵌套、共享定义的行为与 SU 一致。

**2. 工具直切。** 任何工具进行中，直接按另一个工具的快捷键立即切换，不用先按 Esc（例如画线中途按 R 直接换矩形）。只有一个例外：正在数字输入（VCB 有内容）时，字母先当 VCB 后缀（如 `24s` 的 s），输完回车后再按切换键。M/Q/S 三个原生委托工具在拖拽进行中按不了键（Blender 原生工具的 modal 吃按键），点一下鼠标确认后即可切换。

**3. 全部工具。** 除沙盒外，方案内的工具已全部落地（见下）。

## 本版新增（按组）

- **推/拉打洞（P4）**：向内推到底自动打穿成洞，预览到对面时钳制并提示“偏移已受限”。VCB 输精确值、双击复用同样打洞。
- **路径跟随手动模式**：不预选边时，先点截面、再逐条点路径边（每点一段），Enter 结束；Alt+点面用其周长作路径。预选边仍是自动模式。
- **相交面**：编辑菜单 / 右键菜单 → 与模型/与上下文/与选择内容相交。含共面重叠处理；被穿过的面会重建（材质保留）。
- **柔化边线对话框**：角度阈值 + 平滑法线 + 柔化共面。橡皮擦 Ctrl=柔化、Ctrl+Shift=取消柔化、Shift=隐藏、Alt=清全部标志。
- **隐藏**：Hide / Unhide 全部/上一个；View 菜单“隐藏的几何体”开关以虚线显示隐藏边（K=后边线开关）。
- **标记（Tags）**：N 面板 Tags 列表（新建/删除/重命名、眼睛开关可见性、颜色），Tag 工具点对象指定活动标记，“按标记着色”显示标记色包围框。
- **材质**：N 面板 Materials（活动材质、颜色、纹理尺寸），Paint Bucket（B）四种模式：面/相连相同/全部相同/整个对象，Alt 取样；带图材质按真实尺寸生成 UV。默认材质正面白、反面蓝灰（与 SU 一致）。
- **剖切面**：Section Plane 工具点面放置，活动剖切面实时剖切显示；面板可切换/反转/删除；“从切片创建群组”生成切口边线组。
- **参考线/绘图轴持久化**：随文件保存， reopen 后仍在。
- **卷尺（T）**：两点测距；从边开始拉参考线；Ctrl+点放参考点；测距后输数值回车可整体缩放模型（有确认对话框）。
- **量角器**：三点（中心/0°/角度）放带角度参考线，VCB 可输精确角度。
- **坐标轴工具**：三点放置绘图坐标轴；菜单有重置。
- **尺寸标注/文字/3D 文字**：尺寸标注三点放置（端点跟随对象移动）；文字工具点一点输注释（带指引线）；3D 文字对话框生成挤出网格文字（含中文，自动找系统 CJK 字体）。
- **相机**：Orbit（O）/Pan（H）/Zoom（Z）/Zoom Window（Ctrl+Shift+W）/Position Camera/Walk/Look Around；标准视图 F2–F5 + Iso；Zoom Extents（Shift+Z）；平行投影（N）；上一/下一视图；视野角对话框。
- **场景/样式**：Scenes 面板保存/恢复视图+标记可见性+活动剖切面+隐藏状态；Styles 面板五个显示预设 + 按轴着色开关。
- **实体工具**：Outer Shell / Union / Subtract / Trim / Intersect / Split（活动对象为刀具，其余选中实体为目标；仅闭合流形实体可用）。
- **套索（Shift+Space）**：拖圈选择，顺时针=全含、逆时针=相交；松开后自动回到选择工具。
- **搜索（Shift+S）**：全部 SU 工具/命令的菜单。
- **右键菜单**：对象/编辑模式右键都有 SketchUp 分区（成组、炸开、相交、柔化、隐藏等）。
- **持久叠加层**：SU 模式下常驻显示参考线、剖切面、绘图轴、尺寸标注/注释、当前上下文虚线框、后边线/隐藏边/按轴着色边。

## 已知限制（诚实标注）

- 旋转无交互拾取中心/折叠轴（轴心固定为选择中心）、缩放无包围盒手柄、旋转阵列需手输角度、VCB 重输随原生委托取消（改用原生数字输入）——0.5.0 已有取舍，本版未变。
- 两点透视为近似实现（调平地平线）：Blender 没有偏轴投影，做不出真两点透视。
- 反面材质：Blender 无法给单个面指定反面材质；只有默认材质有独立的反面色，喷涂过的面正反同材质。
- 容器材质：点容器喷涂时，材质会烤进当前默认材质的面（SU 是容器级材质、后建的面自动继承；Blender 结构做不到动态继承）。
- 剖切显示用布尔修改器：大模型活动剖切时刷新可能变慢；关剖切即恢复。
- Walk 是基础版（WASD + 拖动环视，无碰撞/重力）。
- 按标记着色显示为包围框着色（非 SU 的面着色）。
- 隐藏的面在编辑模式用 Blender 的隐藏机制：个别原生操作可能跳过隐藏面，与 SU 的隐藏语义略有差异。
- 沙盒工具（地形/曲面细分）按已批方案不进首期。
- 本版仍只在 Linux 这边自测过，未上 Windows 真机；中文界面文字走系统 CJK 字体加载，个别生僻字形以真机为准。
